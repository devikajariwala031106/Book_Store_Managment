📚 Book Store Management System

A modern and fully responsive Book Store Management System developed using Node.js, Express.js, MongoDB, EJS, and Multer following proper MVC architecture. This project is designed to manage book records efficiently through a clean browser-based interface with complete CRUD operations and premium UI/UX design.

✨ Project Highlights:

🔹 Add new books with complete details and cover image upload

🔹 View all books in attractive card/table layout

🔹 Update existing book information and replace images

🔹 Delete book records permanently from database

🔹 Upload and manage book cover images using Multer

🔹 Store and fetch data dynamically using MongoDB

🔹 Responsive and modern frontend using EJS templates

🔹 Professional dashboard with summary cards and navigation

🔹 Clean MVC folder structure for better project organization

🔹 Smooth UI animations, glassmorphism effects, and modern styling

🔹 Beginner-friendly and examiner-friendly project implementation

🛠️ Technologies Used:

🚀 Node.js

🚀 Express.js

🚀 MongoDB + Mongoose

🚀 EJS Template Engine

🚀 Multer

🚀 Bootstrap/Tailwind CSS

🚀 Nodemon

📌 Core Features:

✅ Full CRUD Functionality

✅ Dynamic Database Connectivity

✅ Image Upload Management

✅ Responsive User Interface

✅ Form Handling & Validation

✅ Browser-Based Book Management

📂 Modules Included:

📖 Add Book Module

📚 View Books Module

✏️ Edit Book Module

❌ Delete Book Module

🖼️ Image Upload Module

🎯 Project Objective:
The main objective of this project is to simplify book record management using modern web technologies while implementing important backend concepts like routing, database handling, MVC structure, and file uploading in a real-world application.

🏆 Academic Concepts Covered:

📌 Express Routing

📌 MongoDB Operations

📌 CRUD Operations

📌 MVC Architecture

📌 Form Handling

📌 File Upload using Multer

📌 Dynamic Frontend Rendering with EJS

📌 Database Connectivity using Mongoose


💡 This project is ideal for academic submission, practical implementation, and understanding full-stack CRUD application development using Node.js ecosystem.
